# TCK-017 — Order creation API (COD)

**Owner:** Backend
**Depends on:** TCK-016
**Priority:** P0

## Goal
Implement `POST /api/orders` to create a COD order with server-authoritative totals and atomic stock decrement.

## Acceptance criteria
- [ ] Accepts `{ customerName, customerPhone, city, address, notes?, items: [{productId, quantity}] }`
- [ ] Zod validation incl. Moroccan phone format; required fields enforced → 422 on failure
- [ ] Server re-reads each product price + stock from DB; ignores any client-sent price
- [ ] Validates `quantity <= stock`; out-of-stock → 409 naming the product
- [ ] Inserts `orders` (status `pending`, `paymentMethod 'cod'`, computed `total`) + `order_items` and decrements stock **in one transaction**
- [ ] Attaches `userId` if a session exists; guests allowed
- [ ] Returns `201 { orderId, total, status }`
- [ ] `GET /api/orders` returns the session user's own orders only

## Technical notes
Total computed in integer minor units. Use a Drizzle transaction so insert + stock decrement are atomic. Query logic in `lib/queries/orders.ts`. Rate-limit candidate (public write) — basic per-IP limit acceptable in Phase 1.
