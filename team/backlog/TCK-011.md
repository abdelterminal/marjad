# TCK-011 — Product listing page (filters, sort, pagination)

**Owner:** Frontend
**Depends on:** TCK-010, TCK-012
**Priority:** P0

## Goal
Build `/[locale]/products` with a responsive grid, category + price filters, sort-by and pagination — all driven by URL searchParams.

## Acceptance criteria
- [ ] Server Component reads `searchParams` and fetches via `lib/queries/products.ts`
- [ ] Category filter (from categories), price min/max filter, sort-by (newest, price asc, price desc)
- [ ] Pagination controls reflecting `total`/`page`
- [ ] Filter/sort controls are client islands that push to the URL (no client data fetching)
- [ ] Shareable/back-button-correct URLs
- [ ] Empty state when no results; loading handled gracefully
- [ ] Responsive grid + RTL-correct controls

## Technical notes
Filters mutate `router.push` with updated searchParams; the page re-renders server-side. See architecture §3 "Filters via URL". Reuse ProductCard (TCK-012). Keep price filter inputs validated (numeric, min<=max).
