# TCK-003 — Shadcn/ui setup + base UI primitives

**Owner:** Frontend
**Depends on:** TCK-001
**Priority:** P0

## Goal
Initialize shadcn/ui against the brand tokens and add the primitive components Phase 1 needs.

## Acceptance criteria
- [ ] shadcn/ui initialized (components land in `src/components/ui/`)
- [ ] shadcn theme variables mapped to brand tokens (no default slate palette)
- [ ] Added primitives: `button`, `input`, `label`, `textarea`, `select`, `dialog`, `sheet`, `dropdown-menu`, `badge`, `card`, `table`, `sonner` (toast)
- [ ] `lucide-react` available for icons
- [ ] Primitives render correctly in both LTR and RTL
- [ ] `cn()` helper (`clsx` + `tailwind-merge`) available at `src/lib/utils.ts`

## Technical notes
Only add components actually used in Phase 1 to keep the bundle lean (NFR §7). Verify each primitive respects logical CSS props for RTL. Toasts (sonner) used for cart/add and admin save feedback.
