# TCK-004 — Header (RTL-aware, responsive)

**Owner:** Frontend
**Depends on:** TCK-002, TCK-003
**Priority:** P0

## Goal
Build the global Header with logo placeholder, nav, language switcher, cart icon and auth CTA.

## Acceptance criteria
- [ ] Logo placeholder (text "MARJAD") links to locale home
- [ ] Primary nav: Home, Products, (category links optional)
- [ ] Language switcher slot (TCK-006), cart icon slot (TCK-015), auth CTA slot (TCK-019)
- [ ] Fully responsive: mobile shows a hamburger/sheet menu, desktop shows inline nav
- [ ] RTL-correct: nav flows right-to-left in AR, icons mirror appropriately
- [ ] Sticky on scroll; uses brand surface + border tokens
- [ ] All strings come from `messages/fr.json` + `messages/ar.json`

## Technical notes
Server Component shell embedding client islands (switcher, cart icon, auth CTA, mobile menu sheet). Use logical utilities (`ms-/me-/ps-/pe-`). Mobile menu = shadcn `Sheet`. Cart icon and auth CTA can be placeholder components until their tickets land — expose the slots now.
