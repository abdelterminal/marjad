# TCK-022 — User account: profile edit

**Owner:** Both
**Depends on:** TCK-019
**Priority:** P0

## Goal
Let logged-in users view and edit their profile (name, phone, address).

## Acceptance criteria
- [ ] `/[locale]/account/profile` shows current name, email (read-only), phone
- [ ] Editable: name, phone (and a default address if stored)
- [ ] `PATCH` endpoint (e.g. `/api/account/profile`) updates the session user's row only; Zod-validated
- [ ] Email change out of scope Phase 1 (read-only)
- [ ] Success/error feedback (toast); localized; RTL-correct

## Technical notes
Protected via `requireUser()`. Update restricted to `session.user.id`. The `users` table has `name`, `phone` (no address column) — a default address can be stored only if a column exists; since none does, Phase 1 profile edits cover name + phone (address is captured per-order at checkout). Do not add a column for address in Phase 1.
