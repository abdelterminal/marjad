# TCK-006 — Locale-aware root layout wiring + language switcher

**Owner:** Frontend
**Depends on:** TCK-004, TCK-005
**Priority:** P0

## Goal
Compose Header + Footer into `[locale]/layout.tsx` and implement the FR↔AR language switcher that preserves the current path.

## Acceptance criteria
- [ ] `[locale]/layout.tsx` renders Header, `{children}`, Footer inside a flex column (sticky footer)
- [ ] `dir`/`lang` continue to be set correctly (already present — do not regress)
- [ ] Mount points/providers added: cart store hydration-safe, toaster, NextIntlClientProvider (exists)
- [ ] Language switcher toggles fr↔ar while staying on the same page (e.g. `/fr/products/x` ↔ `/ar/products/x`)
- [ ] Switcher shows the *other* language label and updates `dir` after navigation
- [ ] No hydration warnings

## Technical notes
Use next-intl's `Link`/`usePathname`/`useRouter` from the routing wrapper to swap locale while preserving pathname + searchParams. Keep the switcher a small client island. The cart store is client-only — ensure SSR-safe hydration (badge renders after mount).
