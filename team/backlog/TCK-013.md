# TCK-013 — Product detail page (gallery + add to cart)

**Owner:** Frontend
**Depends on:** TCK-010, TCK-012, TCK-014
**Priority:** P0

## Goal
Build `/[locale]/products/[slug]` with image gallery, bilingual name/description, MAD price and add-to-cart.

## Acceptance criteria
- [ ] Server-fetches the product by slug via `lib/queries/products.ts`; 404 if unpublished/missing
- [ ] Image gallery: main image + thumbnails (client island for switching)
- [ ] Localized name + description, price (and compare-at) in MAD
- [ ] Quantity selector + Add to cart (writes to Zustand, opens drawer / toast)
- [ ] Stock-aware: disable add when out of stock; cap qty at stock
- [ ] Responsive + RTL-correct (gallery + content order mirror)
- [ ] SEO: localized `<title>`/meta via `generateMetadata`

## Technical notes
Gallery thumbnail switcher and add-to-cart are the client islands; the rest is server-rendered. Use `next/image` with `priority` only on the primary image. AddToCart pushes `{productId, slug, name*, price, image, quantity}` to the store.
