# TCK-012 — Shared ProductCard + ProductGrid

**Owner:** Frontend
**Depends on:** TCK-003
**Priority:** P0

## Goal
Build the reusable product card and grid used by homepage and listing.

## Acceptance criteria
- [ ] `ProductCard`: image (next/image, WebP, lazy), localized name, price (MAD), compare-at price strikethrough when present, link to detail
- [ ] "Out of stock" / low-stock indicator when `stock <= 0`
- [ ] `ProductGrid`: responsive columns, consistent gaps, RTL-correct
- [ ] Card uses brand tokens (card radius, shadow, border)
- [ ] Optional inline add-to-cart button slot (wired in TCK-014)

## Technical notes
Server Component for card markup; the add-to-cart button inside is the only client island (TCK-014). Use `lib/money.ts` for price formatting. Explicit image dimensions to avoid CLS. This is the single source for product cards — homepage and listing must both consume it.
