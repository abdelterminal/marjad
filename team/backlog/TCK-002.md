# TCK-002 — Bilingual typography setup (FR + AR fonts)

**Owner:** Frontend
**Depends on:** TCK-001
**Priority:** P0

## Goal
Load and wire the display + body fonts for both locales with no layout shift, switching correctly per locale.

## Acceptance criteria
- [ ] Display: Playfair Display (FR) / Amiri (AR); Body/UI: Inter (FR) / Cairo (AR) loaded via `next/font`
- [ ] Font family applied per locale (Latin fonts for `fr`, Arabic fonts for `ar`) without FOUT/CLS
- [ ] `font-display: swap`; display font preloaded
- [ ] Heading utility uses the display font; body uses the UI font
- [ ] Prices/numbers render in Inter consistently in both locales
- [ ] AR text renders correctly RTL with Amiri/Cairo

## Technical notes
Use `next/font/google` and assign CSS variables, then map them in `@theme` (`--font-display`, `--font-body`). In `[locale]/layout.tsx` choose the variable set based on `locale`. Subset to latin + arabic only.
