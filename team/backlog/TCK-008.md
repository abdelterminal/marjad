# TCK-008 — Homepage featured products grid

**Owner:** Both
**Depends on:** TCK-007, TCK-010, TCK-012
**Priority:** P0

## Goal
Show featured products on the homepage using the shared ProductCard/ProductGrid.

## Acceptance criteria
- [ ] Server-fetches published products where `isFeatured = true` (limit ~8)
- [ ] Renders via shared `ProductGrid` / `ProductCard` (TCK-012)
- [ ] "View all" link → products listing
- [ ] Empty state when no featured products
- [ ] Responsive grid, RTL-correct, localized name + price (MAD)

## Technical notes
Use `lib/queries/products.ts` server-side (no client fetch). Reuse ProductCard from TCK-012 — do not build a second card. Price formatting via `lib/money.ts`.
