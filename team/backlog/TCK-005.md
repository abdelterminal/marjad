# TCK-005 — Footer (RTL-aware, responsive)

**Owner:** Frontend
**Depends on:** TCK-002, TCK-003
**Priority:** P0

## Goal
Build the global Footer with brand info, navigation links, and locale-correct layout.

## Acceptance criteria
- [ ] Columns: brand/tagline, quick links (products, account), legal/contact placeholders
- [ ] Tagline placeholder "L'art de décorer / فن التزيين" shown per locale
- [ ] Responsive: stacks on mobile, columns on desktop
- [ ] RTL-correct alignment in AR
- [ ] Uses surface-alt + border + text-muted tokens
- [ ] Strings from message files

## Technical notes
Server Component. Keep it static (no client JS). Social/contact are placeholders until brand assets land.
