# TCK-014 — Cart state store (Zustand + localStorage)

**Owner:** Frontend
**Depends on:** TCK-006
**Priority:** P0

## Goal
Implement the client cart store with localStorage persistence and add-to-cart action.

## Acceptance criteria
- [ ] `lib/cart-store.ts` Zustand store with `persist` → localStorage
- [ ] Actions: `add(item, qty)`, `setQty(productId, qty)`, `remove(productId)`, `clear()`
- [ ] Derived selectors: `itemCount`, `subtotal` (computed, not stored)
- [ ] Adding an existing product increments quantity (capped at stock if provided)
- [ ] Hydration-safe (no SSR mismatch; count renders after mount)
- [ ] `AddToCartButton` client component fires `add` and gives feedback (toast/drawer open)

## Technical notes
Store shape per architecture §6. Subtotal computed in integer minor units to avoid float drift, formatted via `lib/money.ts`. Prices in the store are display-only; server recomputes at checkout. Do not store derived totals.
