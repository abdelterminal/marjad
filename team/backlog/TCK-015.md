# TCK-015 — Cart slide-over drawer UI

**Owner:** Frontend
**Depends on:** TCK-014
**Priority:** P0

## Goal
Build the cart drawer (slide-over) with line items, quantity controls, subtotal and checkout CTA, plus the header cart icon with badge.

## Acceptance criteria
- [ ] Header cart icon shows live item count badge (client island)
- [ ] Clicking icon opens a shadcn `Sheet` drawer (slides from end side; RTL-correct)
- [ ] Line items: thumbnail, localized name, unit price, qty stepper, remove
- [ ] Subtotal in MAD; "Proceed to checkout" → `/[locale]/checkout`
- [ ] Empty cart state with CTA to browse products
- [ ] Updates reflect immediately from the store; responsive

## Technical notes
Drawer reads/writes the Zustand store (TCK-014). Use `Sheet` with `side` chosen by `dir` (end side). No DB calls here. Checkout button disabled when cart empty.
