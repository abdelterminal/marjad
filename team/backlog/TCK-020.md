# TCK-020 — Auth modal (login + register) + session-aware header

**Owner:** Frontend
**Depends on:** TCK-019, TCK-006
**Priority:** P0

## Goal
Build the login/register modal and make the header reflect auth state.

## Acceptance criteria
- [ ] shadcn `Dialog` modal with Login and Register tabs (not separate pages)
- [ ] Login calls `signIn('credentials', ...)`; Register calls `POST /api/auth/register` then signs in
- [ ] Client validation + localized inline errors; loading + error states
- [ ] Header auth CTA: shows "Login" when logged out; shows account menu (name, account link, logout) when logged in
- [ ] Logout via `signOut`
- [ ] Responsive + RTL-correct

## Technical notes
Modal is a client island. Header reads session (server-side `auth()` for the shell, or a session provider for the client menu). On successful register, auto sign-in then close modal. Keep error copy generic for failed login.
