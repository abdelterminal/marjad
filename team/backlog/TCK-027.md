# TCK-027 — Admin dashboard

**Owner:** Both
**Depends on:** TCK-026
**Priority:** P0

## Goal
Build the admin dashboard with core KPIs and recent orders.

## Acceptance criteria
- [ ] Cards: total orders, total revenue (delivered or all per definition), pending count
- [ ] Recent orders list (latest N) linking to order detail
- [ ] Aggregations computed server-side via Drizzle
- [ ] Revenue + counts accurate; MAD formatting
- [ ] Responsive admin layout; admin-gated

## Technical notes
Server Component; aggregate queries in `lib/queries/orders.ts`. Define "revenue" explicitly (recommend: sum of `total` for `delivered` orders, plus show pending pipeline separately). No charts library required in Phase 1 — simple cards + list keep the bundle lean.
