# TCK-025 — Admin category management

**Owner:** Both
**Depends on:** TCK-023
**Priority:** P0

## Goal
Manage categories in admin: list, create, edit, delete, with parent/child support.

## Acceptance criteria
- [ ] `GET/POST /api/admin/categories`, `PATCH/DELETE /api/admin/categories/[id]` (admin-gated)
- [ ] Form collects `nameFr`, `nameAr`, `nameEn` (NOT NULL in schema), optional `parentId`, slug auto-generated
- [ ] List shows hierarchy (parent → children)
- [ ] Delete blocked (409) when products reference the category, or requires reassignment
- [ ] Zod validation; slug uniqueness handled
- [ ] Save/error feedback

## Technical notes
**Schema flag (architecture §5.3):** `categories.nameEn` is NOT NULL even though the storefront is FR/AR only — the form MUST supply it (collect it, or default to `nameFr`). Recommended: collect it. Do not drop the column. Queries in `lib/queries/categories.ts`.
