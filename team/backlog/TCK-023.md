# TCK-023 — Admin shell + auth gate (middleware + layout)

**Owner:** Both
**Depends on:** TCK-019
**Priority:** P0

## Goal
Create the `/admin` layout (outside `[locale]`, French only) and enforce admin-only access at every layer.

## Acceptance criteria
- [ ] `app/admin/layout.tsx` with sidebar nav (Dashboard, Products, Categories, Orders) + logout
- [ ] Admin is French-only, NOT under `[locale]`
- [ ] `proxy.ts`/middleware blocks `/admin/**` and `/api/admin/**` unless JWT present AND `role === 'admin'` (redirect/401 otherwise)
- [ ] Each admin page also calls `requireAdmin()` server-side (defense in depth)
- [ ] Non-admins (and guests) cannot reach any admin route or API
- [ ] Responsive admin shell (collapsible sidebar on mobile)

## Technical notes
Architecture §8: three layers — middleware, page guard, API guard. Extend the existing next-intl middleware to chain an admin check (the next-intl matcher already excludes `/admin`; add explicit handling so admin routes get the role gate). Keep admin LTR/French — no locale routing.
