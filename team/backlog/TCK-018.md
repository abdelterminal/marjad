# TCK-018 — Checkout page + order confirmation

**Owner:** Frontend
**Depends on:** TCK-015, TCK-017
**Priority:** P0

## Goal
Build the COD checkout form and the post-order confirmation screen.

## Acceptance criteria
- [ ] `/[locale]/checkout` form: name, phone (Moroccan), city, address, optional notes
- [ ] Client validation (react-hook-form + Zod) mirroring server rules; inline errors localized
- [ ] Order summary (line items + subtotal) from the cart store
- [ ] Submit → `POST /api/orders` with `items: [{productId, quantity}]`; on success `clear()` cart and redirect to confirmation
- [ ] Pre-fills name/phone from session if logged in
- [ ] Redirect to cart/products if cart empty
- [ ] `/[locale]/checkout/confirmation/[orderId]` shows order number, total, COD notice, status `pending`
- [ ] Responsive + RTL-correct

## Technical notes
Never send prices from the client — only `{productId, quantity}`. Confirmation page server-fetches the order (ownership/guest-token consideration: for guests show minimal confirmation from the POST response/redirect param; for logged-in users verify ownership). Show a "you'll be contacted to confirm" COD message.
