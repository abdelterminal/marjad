# TCK-009 — Homepage category showcase

**Owner:** Both
**Depends on:** TCK-007
**Priority:** P0

## Goal
Display top-level categories as a visual showcase linking into filtered listings.

## Acceptance criteria
- [ ] Server-fetches top-level categories (`parentId IS NULL`)
- [ ] Each tile links to `/[locale]/products?category=<slug>`
- [ ] Localized category name (FR/AR)
- [ ] Responsive tiles, RTL-correct
- [ ] Empty/placeholder state if no categories

## Technical notes
Use `lib/queries/categories.ts`. Category images are optional placeholders in Phase 1 (schema has no category image column — use a neutral tile or first product image; do NOT add a column for this in Phase 1).
