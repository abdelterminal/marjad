# TCK-024 — Admin product CRUD + image upload

**Owner:** Both
**Depends on:** TCK-023, TCK-016
**Priority:** P0

## Goal
Full product management in admin: list, create, edit, delete, with WebP image upload.

## Acceptance criteria
- [ ] `GET/POST /api/admin/products`, `PATCH/DELETE /api/admin/products/[id]` (admin-gated)
- [ ] Product list page with search + pagination (includes unpublished)
- [ ] Create/edit form: nameFr, nameAr, descriptionFr, descriptionAr, price, compareAtPrice, stock, category, images, isPublished, isFeatured
- [ ] Slug auto-generated from nameFr with uniqueness handling
- [ ] `POST /api/admin/uploads`: admin-only, MIME allowlist (jpeg/png/webp), size cap, re-encode to WebP via `sharp`, random uuid filename, write to `/uploads`, return path
- [ ] Multiple images per product (stored in `images text[]`)
- [ ] Zod validation server-side; delete confirms
- [ ] Save/error feedback (toast)

## Technical notes
Image pipeline + validation per architecture §8 (never trust client filename; write only inside `/uploads`; Nginx serves it). Forms are client islands; queries in `lib/queries/products.ts`. Reuse `lib/slug.ts` and `lib/images.ts`. Price stored as numeric string.
