# TCK-010 — Public products API (list + detail)

**Owner:** Backend
**Depends on:** none
**Priority:** P0

## Goal
Expose read-only product endpoints with filtering, sorting and pagination for the storefront.

## Acceptance criteria
- [ ] `GET /api/products` returns published products only, with `category`, `min`, `max`, `sort` (`newest|price_asc|price_desc`), `page`, `pageSize`
- [ ] Response shape `{ items, total, page, pageSize }`
- [ ] `GET /api/products/[slug]` returns a single published product or 404
- [ ] Query params validated via Zod; bad params → 422
- [ ] Parameterized Drizzle queries; no raw SQL string interpolation
- [ ] Reasonable default + max `pageSize`

## Technical notes
Implement query logic in `lib/queries/products.ts` so Server Components can call the same functions directly (listing/detail pages prefer direct query over fetch; the HTTP endpoints exist for any client-side needs). Add indexes (slug, categoryId, isPublished) via the migration in TCK-016/§5.2. `category` filter accepts category slug.
