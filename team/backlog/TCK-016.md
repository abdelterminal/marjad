# TCK-016 — Orders schema migration (payment_method + indexes)

**Owner:** Backend
**Depends on:** none
**Priority:** P0

## Goal
Apply the single required Phase 1 schema change: add `payment_method` to orders and performance indexes.

## Acceptance criteria
- [ ] New Drizzle migration adds `orders.paymentMethod varchar(20) default 'cod' not null`
- [ ] Indexes added: `products(slug)`, `products(category_id)`, `products(is_published)`, `orders(status)`, `orders(user_id)`
- [ ] `schema.ts` updated to match; `db:generate` + `db:migrate` run cleanly
- [ ] No data loss; migration is reversible/documented
- [ ] Existing 7 tables otherwise unchanged

## Technical notes
This is the ONLY schema change for Phase 1 (architecture §5.2). `products.slug` may already be unique-indexed — only add if missing. Run via `pnpm db:generate` then `db:migrate`. Do not alter existing columns/enums (the `processing` status and `nameEn` stay as-is).
