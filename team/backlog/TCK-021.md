# TCK-021 — User account: order history

**Owner:** Both
**Depends on:** TCK-019, TCK-017
**Priority:** P0

## Goal
Build `/[locale]/account` showing the logged-in user's order history, route-protected.

## Acceptance criteria
- [ ] Route protected: unauthenticated users redirected to home + auth modal (or login)
- [ ] Lists the session user's orders (date, order #, total, status badge)
- [ ] Order detail view (items, quantities, totals, shipping info, status)
- [ ] Only the user's own orders are accessible (no IDOR)
- [ ] Localized status labels + MAD totals; responsive + RTL-correct
- [ ] Empty state when no orders

## Technical notes
Server-fetch via `lib/queries/orders.ts` filtered by `session.user.id`; enforce ownership on detail. Use `requireUser()` guard. Reuse the order status badge component (shared with admin, TCK-026).
